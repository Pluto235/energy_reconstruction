Crab SED v5 PSF Aperture Comparison

This report compares 4 PSF aperture definitions under the same v4 response contract: each branch has its own Stage B PSF artifact, aperture-conditioned Stage A response, annulus-normalized Stage D background, Stage E signal with containment_r_opt=1, Stage F fit, and Stage G SED points. The target containment is the existing Rayleigh contract 1 - exp(-0.5 * 1.58^2), not a newly rounded 0.715 scalar.

For this v5 run the two-1D Gaussian aperture radius is numerically very close to the Rayleigh baseline: r_opt(two-1D) / r_opt(Rayleigh) ranges from 0.99439 to 1.0006, with median 1. The fitted anisotropy is modest: sigma_x/sigma_y spans 0.7942-1.16 with median 0.9963. This is why the grey r_opt markers are visually almost indistinguishable from the Rayleigh baseline.
