Crab SED v6 64748 reselect44 - Scheme R - Double-Rayleigh Poisson-Unbinned Background

Scheme R - Double-Rayleigh PSF with grid-free (unbinned) Poisson curvature fit. v6 chain for v6_64748_nhit100_reselect44_split56_miss030_double_rayleigh_scheme_R_fixed712979_poisson_unbinned. Identical to the frozen poisson_pooled experiment (same Stage C events, PSF, response, selector, and the same frozen pooling manifest) except that the 7 order-2 (curvature) cells fit their shape from the continuous OFF-annulus event coordinates instead of a 0.1° pixel histogram. The on-source background is the same analytic centered aperture integral B_on = N_ann · ∫_disk q / ∫_annulus q.

Why this experiment: the pooled-Poisson experiment failed its registered grid-convergence gate (max |ΔB_on|/σ = 0.786 > 0.5). Review proved the entire instability lives in the single radial-trace scalar τ = c_xx + c_yy of the 7 order-2 cells, discretised by the pixel grid. The unbinned fit estimates τ from continuous event coordinates, so B_on is grid-invariant by construction. The plane/constant cells are unchanged (their B_on is already grid-exact geometry).
Independent acceptance changed: because unbinned B_on no longer depends on grid phase/resolution, the 12-branch grid is retained as a regression (envelope must be ≈0) and the new registered acceptance axis is a time split (median-MJD halves), gated on the exposure-free shape factor g(τ)=B_on/N_ann.

Bootstrap Covariance Evidence

Unbinned parametric bootstrap: for each order-2 cell draw M ~ Poisson(N_ann) OFF events, resample the observed event coordinates with replacement, refit the shape unbinned, and recompute B_on from the analytic centered integrals. Order≤1 cells use the analytic Poisson variance of N_ann (shape-independent). The covariance-aware fit uses diag(N_on) + Cov(B_on) through a Cholesky solve; it is diagnostic and does not replace the conservative preferred fit.

Method Note: binned vs unbinned curvature

For a source-centered aperture, B_on = N_ann · (πr² + ¼πr⁴τ) / (π(r_out²-r_in²) + ¼π(r_out⁴-r_in⁴)τ) depends only on the intercept and the radial trace τ = c_xx + c_yy; all linear and anisotropic polynomial terms integrate to zero over the centered region. Only τ can move B_on, and only the 7 order-2 cells carry a nonzero τ.

  • Binned: OFF events are histogrammed onto a 0.1° grid and a multinomial is fit to pixel counts. The pixel staircase discretises the annulus and biases τ as a function of grid step/phase (the source of the 0.786σ failure; the production 0.1° grid underestimated a test τ by ~50%).
  • Unbinned: the profiled multinomial -∑_e log q(x_e,y_e) + N_ann·log∫_annulus q is evaluated at the continuous event coordinates with an analytic annulus normalization. It is the h→0 limit of the binned fit (verified: binned τ converges monotonically to the unbinned value as the grid refines) and carries no grid dependence.
