Roadmap v2: raw65 ledger + frozen selector

v2 的核心是把 cell 选择推迟到拟合阶段：Stage A-E 保留可追踪的原始 cell 和 metadata，Stage F/G 只使用预冻结 selector。任何 Crab on-source 结果只能作为诊断 flag，不能作为正式筛选规则。

  1. Stage A/B/C/D/E 都跑同一套 v2_raw65 非重叠 cell ledger。

2. Cell Ledger 与 Selector

2.1 raw ledger: v2_raw65

v2_raw65 定义为旧 acceptable pool 去掉旧 >=2000 open bin 后的 60 个 cell，再加入 v2 [2000,3000) 五个 high-Nhit cell，总计 65 个互斥 cell。

2.2 baseline selector: v2_baseline26

默认 Stage F/G baseline 是 26 个预冻结 cells：当前 cell_selection_v2p1.csv 的 23 个 cells，加上 [100,200) physical ridge 三格：[2,3)、[3,3.25)、[3.25,3.5)。

3. v2.0 Milestone: raw65 + direct expectation

Stage A/B

Stage A 对 raw65 全部构建 response 和 A_eff，Stage B 对 raw65 全部构建 PSF、r_opt 和 quality flags。质量差的 cell 打 flag，不在上游删除。

Stage C

Stage C 用 raw65 规约观测 parquet，保留下游所需列，并在 metadata 中记录 out-of-ledger counts 与 Crab-centered ROI coverage。

Stage D/E

v2.0 默认 background_mode = crab_roi_local，background_form = direct_expectation。Stage D 输出 B_on,b，Stage E 对 raw65 全部输出 N_on、B_on、excess 和 known-background Poisson diagnostic。Li-Ma 标记为 not applicable。

Stage F/G

Stage F/G 读取 raw65 artifacts，但默认只 include v2_baseline26。报告必须记录 raw ledger version、selector version、included/excluded cell ids 和 excluded reasons。v2.0 SED 是 diagnostic SED。

4. v2.1 Milestone: true off counts / Li-Ma

v2.1 在 v2.0 闭环后升级 Stage D/E 的统计口径，在 rho < 6 deg fiducial ROI 内定义真实 off regions。

  • Stage D 输出 N_off,b、alpha_b、B_on,b = alpha_b * N_off,b 和 off geometry metadata。
  • Stage E 输出 excess_b = N_on,b - alpha_b N_off,b、sqrt(N_on,b + alpha_b^2 N_off,b) 和 Li-Ma significance。
  • Stage F/G 默认仍使用 v2_baseline26，保证 v2.0/v2.1 差异主要来自背景统计升级，而不是 selector 改变。

5. Systematics 与验证

  1. raw65 completeness：Stage A-E 的 cell id、bin、role 必须一致。
  2. selector freeze audit：Stage F/G 必须证明 selector 文件在 fit 前已存在，且未使用 source-result columns 自动筛选。
  3. low-Nhit diagnostics：[30,100) 永久 diagnostic-only；[100,200) 只允许 physical ridge 三格进入 baseline。
  4. high-energy diagnostics：[2000,3000) 五格保留在 raw65；默认 baseline 只纳入 v2p1 保留的两格。
  5. ROI edge sensitivity：重跑 rho < 5.5、6.0、6.5 deg 对照。
  6. background method sensitivity：v2.1 至少比较 equal-Dec sideband 和 ring/annulus。
  7. 1D vs 2D consistency：二维响应 marginalise 后的一维 Nhit fit 应与二维 baseline fit 一致。
  8. response closure：raw65 和 baseline26 都要给 closure summary。
