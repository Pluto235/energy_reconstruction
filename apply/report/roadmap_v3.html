Roadmap v3

HAWC-style 二维 cell selection 与 Crab-local annulus 2D surface background 的 Stage A-G 重构路线。

Markdown source

目标

v3 同时升级 cell selection 和 Stage D 背景估计：用 MC/几何/PSF/背景稳定性定义冻结 selector，并用 1.5<rho<3.5 deg 环带拟合二阶 2D 背景曲面，外推到 Crab 核心区估计 B_on。

v3 最终产物必须形成 crab_sed_v3_stage_a_to_g_report.html，至少包含 v2 final report 的所有关键图，并新增背景曲面拟合诊断。

固定决策

  1. Nhit 下限改为 125；最低 bin 直接使用 [125,200)，不保留 <125。
  2. Stage C 必须能访问 Nhit 并重新赋予 v3 cell_id。
  3. 背景训练环带默认 1.5-3.5 deg，低 Nhit 宽 PSF cell 可按 prefit PSF 规则外移。
  4. nominal 背景曲面为二阶模型：1, x, y, x^2, xy, y^2。
  5. selector 冻结；不允许用 Crab on-source excess、pull 或 SED residual 回头删 cell。
  6. predE 使用混合网格：[2,3) 拆成两个 0.5 dex bins；[3,5) 保持 0.25 dex；>=5 拆成 [5,6) 和 >=6 两个高能宽 bins。

HAWC 启发

HAWC 使用 shower-size bin B 与 reconstructed-energy bin Ehat 的二维分析 bins。总候选为 9 x 12 = 108，但实际 fit 只使用 MC 分布 central 99% 及质量通过的 bins；GP 使用 40 个 bins，NN 使用 37 个 bins。

v3 对应采用 Nhit bin x ml_logE_pred bin，先建立完整候选网格，再用 MC response、PSF、coverage、背景拟合质量和 reference-spectrum expected sensitivity 做 prefit selector。

Stage A-G

Stage A

对 v3 candidate grid 全量生成 response，并输出 MC central-99% selection inputs。

Stage B

对所有 candidate cells 建 PSF，输出 r_opt、containment、PSF tail risk 和 annulus placement 建议。

Stage C

重新规约观测事件，执行 Nhit >= 125，输出可审计 v3 cell assignment 和 annulus coverage。

Stage D

在 annulus 上拟合二阶 2D surface，外推核心区，输出兼容 Stage E 的 B_on/background_map/excess_map。

Stage E

对 candidate cells 输出 N_on/B_on/excess 和 known-background diagnostics；不删除 cell。

Stage F/G

用冻结 cell_selector_v3_baseline.csv forward-folding，并生成 reconstructed-energy grouped SED points。

Stage D Surface

B(x, y) = a0 + ax*x + ay*y + axx*x^2 + axy*x*y + ayy*y^2

每个 cell 独立拟合。训练像素来自 annulus；输出 surface coefficients、covariance、fit chi2/ndof、condition number、annulus residual 和 core extrapolation warnings。

Implementation Phases

  1. 写入 v3 design artifacts：roadmap_v3.md/html。
  2. 生成 v3 candidate ledger 和 HAWC-style selector prototype。
  3. 重跑 Stage C v3，支持 Nhit >= 125。
  4. 实现 Stage D annulus 2D surface background。
  5. 跑通 Stage E/F/G v3 full chain。
  6. 生成 v3 integrated report 和系统学对照。

已确认与待验证

  1. Stage C 原始 Nhit 字段：已接受推荐，从 ROOT/recovered source 重跑并保留 Nhit audit。
  2. predE binning：[2,3) 一整 dex 太宽，但 0.25 dex 对低能端可能过细，推荐拆成 [2,2.5) 和 [2.5,3)；[3,5) 的 0.25 dex 合理，[4,5) 已经细分；>=5 统计量低，推荐拆成 [5,6) 和 >=6，其中 >=6 主要作为 upper-limit / diagnostic 候选。
  3. annulus 外移上限：已接受推荐，默认到 4.5 deg，必要时 5.0 deg。
  4. surface fit：已接受推荐，v3.0 用二阶加权 least squares，Poisson log-link 做 cross-check。
