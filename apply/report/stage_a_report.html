Stage A 做了什么

Stage A 的目标是为后续 Crab SED forward folding 准备探测器响应。这里的观测单元不是传统的一维 Nhit bin，而是 v1 选择的二维单元 b = (Nhit bin, log10 E_pred bin)。响应函数定义为：

eta_b(E_true, theta_true) = N_pass(b, E_true, theta_true) / N_thrown(E_true, theta_true)

其中分子表示 MC 事件通过选择、完成 ML 能量预测并落入 cell b 的加权事例数；分母表示同一真实能量和真实天顶角 bin 内投放的 primary gamma 加权事例数。有效面积同步输出：

A_eff,b(E, theta) = S0 * cos(theta_true_bin_center) * eta_b(E, theta)，其中 S0 = 4.0e6 m2。上游 t_evth.v[48] injectionArea = 4.0e10 cm2，不是 mm2；投点几何为约 [-1000,1000] m x [-1000,1000] m 的方形 core box。

输入与选择

  • MC inference cache：/mnt/mydisk/WCDA_simulation_binned_response_v1。
  • 能量模型：runs/theta_recoxy_position_embed_midenergy_8666/checkpoints/best_model.pt。
  • v1 cell selection：apply/config/cell_selection_v1.csv，共 18 个 physical-band cells。
  • 观测侧一致 cuts：pincness < 1.1、fitstat == 0、theta < 50 deg、dcedge > 20 m。
  • 真值网格：log10(E_true / GeV) 从 2.0 到 6.0，步长 0.1；theta_true 从 0 到 50 deg，步长 1 deg。

分子和分母

  • 分子从 binned MC ROOT 读取，每个 ROOT 已经按 nv 和 ml_logE_pred 落到对应观测 cell，并保留 mc_energy、mc_theta、mc_weight。
  • 分母来自 /mnt/mydisk/WCDA_simulation_primary_hist/primary_denominator_stage_a.npz，正式权重源是 hntotmc，unweighted hntotmc0 只作诊断。
  • 正式响应使用 mc_weight_baseline，避免把 weighted numerator 和裸 count denominator 混用。

需要再确认的地方

Stage A 当前没有施加 mc_dangle truth cut。 前置 cache 生成命令使用了 --no-cut-dangle，Stage A metadata 也记录 mc_dangle_cut: null。这与观测端可用 cut 保持一致，因为观测数据没有 MC truth dangle；但训练配置快照中存在 dangle_max_deg: 3.0。建议确认这是正式响应的有意选择，而不是遗漏训练侧 truth cut。
