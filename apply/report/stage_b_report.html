Stage B 做了什么

Stage B 的目标不是重新构建有效面积，而是给每个 v1 观测单元提供 Crab 赤纬带上的角分辨率和积分半径。后续 Stage E 会用这里的 r_opt 在 Crab 位置统计 N_on，并与背景估计结合得到 excess 和 Li-Ma 显著性。

输入和一致性检查

  • MC cell cache：/mnt/mydisk/WCDA_simulation_binned_response_v1。
  • Stage A metadata：apply/output/stage_a/response_2d_metadata.json。
  • v1 cell selection：apply/config/cell_selection_v1.csv，共 18 个 cells。
  • Stage B 会拒绝旧版 Stage A：要求 response_type = primary_thrown_response、absolute_effective_area_status = available、weighting = mc_weight_baseline。
  • 真能量范围从 Stage A 继承：log10(E_true / GeV) = [2, 6)；天顶角范围为 0-50 deg。

权重和 PSF 模型

  • baseline 权重为 mc_weight * crab_declination_theta_reweight，只按 Crab 赤纬对应的天顶角分布重权，不引入 Crab 谱假设。
  • Crab 几何参数为 LHAASO 纬度 29.45 deg、Crab 赤纬 22.01 deg，用 uniform hour-angle samples 得到 theta < 50 deg 条件下的 Crab 天顶角分布。
  • baseline sigma_b 用 mc_dangle <= 3 deg 的 core events 做 Rayleigh MLE：sqrt(sum(w r^2) / (2 sum(w)))。
  • 积分半径定义为 r_opt = 1.58 sigma_b。全分布 Rayleigh sigma、r68/r90/r95、tail weight fraction 只作为诊断保存。
为什么没有继续用全分布 MLE？ 旧 Stage B 直接用全部 mc_dangle 做 Rayleigh MLE，低 Nhit 单元会被长尾拖到十几度甚至二十度以上，导致 r_opt 不适合作为 Crab on-region 半径。当前实现把 baseline 收缩到 3 deg core fit，同时把 full-tail sigma 和 tail fraction 放进报告，方便后续判断长尾是否需要更复杂的 PSF 模型。

需要再确认的地方

PSF 口径已经从 roadmap 的“v1 单高斯”细化为“3 deg core Rayleigh fit + full-tail diagnostics”。 这个改动是为避免长尾把积分半径拖到不现实的十几度。建议在 Stage E 之前确认：后续 on-region 是否正式采用 core-fit r_opt，还是需要引入经验优化半径或双成分 PSF。
两个 cell 有 Crab theta support 缺口。 cell 13 缺口概率质量为 0.0831，cell 16 为 0.0624；都低于 0.10 的失败阈值，但需要在 Stage E/F 解释它们对高 theta Crab 轨迹的覆盖不足。
